# TravelMitra

A mobile-first travel planning app prototype.

## Current MVP

- Home dashboard
- Create trip
- Destination and date selection
- Travel-interest selection
- Local experience discovery
- Tirupati hilltop jeep experience example
- Experience details
- Add-to-trip interaction
- Explore tab
- My Trips placeholder
- Profile placeholder

## Build locally

```bash
flutter pub get
flutter run
```

## Build APK with GitHub

Push this repository to GitHub. Then:

1. Open the repository.
2. Open **Actions**.
3. Select **Build Android APK**.
4. Click **Run workflow**.
5. Wait for the build.
6. Open the completed workflow run.
7. Download the `travel-mitra-apk` artifact.
